# 분석 방법·자료 사전

## 사업 선정

공식 엑셀 첫 시트의 `CODE`를 사업 식별자로 사용한다. 행 머리말·빈 행은 제외한다. 실제 분류 5개 중 `주택정비형 재개발`, `공동주택재건축`, `아파트지구재건축`, `단독주택재건축`을 포함한다. `도시정비형 재개발`은 주거 여부가 일괄 확인되지 않아 제외한다. 추진단계 7개(`구역지정`, `추진위`, `조합설립`, `건축심의`, `사업시행`, `관리처분`, `착공`)를 모두 포함한다. 원본에 완료·해제 단계는 없다. 이미 완료·해제된 사업을 임의로 포함하지 않는다. 동일한 358개 사업 목록을 두 Density에 사용한다.

`CODE` 496건은 모두 고유했고 포함 358건, 제외 138건이다. 사업별 위치는 주소 열로만 주어져 있어 토지피복과의 공간 충돌은 아직 검증할 수 없다. 토지피복 원자료 확보 후 위치 검증이 필요하며 산림·수역과 겹친다는 이유만으로 사업을 삭제하지 않는다.

## 지표

- 전체 면적 (A_i=\operatorname{Area}(B_i)), 제외 합집합 (E_i=\operatorname{Area}(B_i\cap(F\cup W))), 잔여 면적 (A_i^*=A_i-E_i) (km²).
- 전체 면적 Density (D_i=R_i/A_i), 보정 Density (D_i^*=R_i/A_i^*) (구역/km²).
- 노후주택 비율 (p_i=O_i/H_i), LQ (=(O_i/H_i)/(O_S/H_S)). (O_S,H_S)는 서울 합계와 중복하지 않고 25개 구를 합산한다. 공식 서울 행과 대조한다.
- 서울 기준 Density는 각각 (\sum R_i/\sum A_i), (\sum R_i/\sum A_i^*)이다. 자치구 Density 단순평균을 쓰지 않는다.
- 관심 지역은 반올림 전 `LQ > 1`과 해당 Density `< 서울 Density`를 동시에 만족할 때만 참이다. 결측 또는 분모 0이면 계산 불가(`null`)다.
- 두 방식의 Density 순위는 내림차순이며 `rank_change = rank_total - rank_adjusted`다. 양수는 보정 후 순위 상승이다.

## 공간 처리

SGIS 원본 EPSG:5179는 미터 단위 투영좌표다. 모든 면적 계산을 여기에 맞추고 1,000,000으로 나눠 km²로 변환한다. 브라우저 경계는 EPSG:4326으로 따로 저장한다. 공식 세분류 벡터 SHP·GPKG·GeoJSON을 받을 경우 실측 분류 열을 명시해 스크립트를 실행한다. 동일 분류 도엽이 겹치거나 산림·수역 경계가 겹쳐도 각각 합집합을 구한 뒤 한 번만 차감한다. 원자료가 래스터이면 이 벡터 파이프라인에 넣지 않는다. 래스터의 범주형 최근접 재투영·경계 셀 집계 방법을 별도로 확정해야 한다.

사용자 제공 EGIS SHP의 실측 분류 열은 `L3_CODE`, 원본 좌표계는 EPSG:5186이다. `scripts/inspect_landcover.py`는 원본을 수정하지 않고 125도엽·329,635도형의 코드·`IMG_DATE`·유효성·도엽 외접 범위 커버리지를 기록한다. 외접 범위는 실제 피복 범위의 **상한**이다. 현재 중랑·노원·구로·강동구가 99.9%에 미달한다. 사용자 지시에 따라 관측된 산림·수역만 EPSG:5179에서 합집합 처리해 자치구 경계에서 차감한다. 미관측 부분은 전체 면적 분모에 남기고 임의로 피복을 채우지 않는다. 따라서 해당 부분에 산림·수역이 더 있다면 산출 Density는 과소평가될 수 있고 서울 기준선과 관심 지역 판정도 달라질 수 있다. 결과 상태는 `provisional_partial_coverage`다. 405건의 원본 링 자기 교차 중 실제 제외 범주의 해당 도형은 `make_valid`로 수선하고 건수·면적 변화를 기록한다. `IMG_DATE`는 영상일자 속성으로만 기록하며, 사용자 지시에 따라 제작연도를 계산 조건으로 사용하지 않는다.

## 공개 필드

| 필드 | 뜻·단위 |
|---|---|
| `code`, `source_boundary_code`, `district` | KOSIS 5자리 코드, SGIS 원본 코드, 구 이름 |
| `renewal_count` | 대상 주거 정비사업 구역 수 |
| `old_homes`, `homes` | 30년 이상 주택 수, 전체 주택 수 (호) |
| `total_km2`, `forest_km2`, `water_km2`, `excluded_union_km2`, `remaining_km2` | 전체·산림·수역·합집합·잔여 면적 (km²) |
| `tile_bbox_coverage_upper_bound` | 자치구와 도엽 외접 범위가 겹치는 면적 비율의 상한. 실제 원자료 커버리지는 이보다 클 수 없음 |
| `old_share`, `lq` | 노후주택 비율, 상대적 집중도 |
| `density_total`, `density_adjusted` | 전체·보정 Density (구역/km²) |
| `rank_total`, `rank_adjusted`, `rank_change` | Density 순위 및 변화 |
| `priority_total`, `priority_adjusted` | 각 서울 기준에 따른 관심 지역 여부 |

노후주택 **비중**과 실제 **호수**를 함께 제공한다. 잔여 면적은 ‘산림·수역 제외 면적’이며 개발 가능 면적 또는 실제 주거지 면적을 의미하지 않는다.
