# 산림·수역 면적 원자료: 이전 VWorld 후보 검토

검토일: 2026-11-01. 기존 `.env`에 `VWORLD_API_KEY`가 설정된 것만 확인했다. 키는 로컬 Python 요청에만 사용했으며 값, 인증 URL, 원응답을 출력하거나 저장하지 않았다. [VWorld 2D 데이터 API 목록](https://www.vworld.kr/dev/v4dv_2ddataguide2_s001.do)과 인증된 [WFS GetCapabilities](https://api.vworld.kr/req/wfs)를 조사했다. API 목록 158건을 검색하고 WFS FeatureType 202건을 확인했다. WFS 응답의 일부 한글 제목은 서버 측에서 깨져 있어, 목록의 한국어 제목과 교차 확인했다.

| 후보 | 기관·목록 갱신일 | 실제 응답 | 판단 |
|---|---|---|---|
| `LT_C_FSDIFRSTS` 산림입지도 | 산림청, VWorld 2019-07-09 | 남산 부근 BOX: `MultiPolygon` 41건, `toyanghyun`·`name` 속성 | 산림의 현재 피복 면적이 아니라 입지·토양 정보다. 산림청 [공식 답변](https://fgis.forest.go.kr/newkfsweb/cop/bbs/selectBoardArticle.do?bbsId=BBSMSTR_1351&nttId=3215560)에 따르면 1:25,000 산림입지도는 2003년 구축 후 현행화되지 않았다. |
| `LT_C_WKMSTRM` 하천망 | 한강홍수통제소, VWorld 2023-06-09 | 한강 주변 BOX: `MultiPolygon` 2건, `riv_nm`·`cat_nam` 속성; 도형 1건은 기하 오류 | 명칭과 범주는 확인되지만 경계가 실제 수면인지, 어느 시점의 수면인지 공식 정의를 확인하지 못했다. 호소 등 수역 전체의 피복이라고도 확인할 수 없다. |

WFS 목록의 산림보호구역, 상수원보호, 유역도 및 카탈로그의 용도지역은 각각 지정·규제·집수 범위다. 이들을 실제 산림 분포 또는 수면으로 바꾸어 쓰지 않는다. 공식 목록에서 `산림`, `임상`, `하천`, `수역`, `토지피복`을 검색했지만 이 분석에 쓸 산림 피복·수면 폴리곤 또는 범주형 원자료는 찾지 못했다. WFS와 데이터 API로 벡터 도형 자체를 받을 수 있다는 것은 확인했으나 의미가 맞는 도형은 확인되지 않았다. WMS 이미지는 면적 계산에 사용하지 않는다.

## 호출 제한과 완전성

`LT_C_FSDIFRSTS`의 작은 BOX에서 63건이 조회됐다. `size=1`은 `record.total=63`, `record.current=1`, `page.total=63`과 도형 1건을 돌려줬고, `size=1000`은 `record.current=63`, `page.total=1`과 63건을 돌려줬다. `size=1001`은 `INVALID_RANGE`였다. 따라서 현재 응답에서 확인한 페이지당 최대 요청 건수는 **1,000건**이다. 이는 해당 레이어와 요청의 실측 결과이며 다른 API나 계정의 일반 규정으로 확대하지 않는다.

적합한 레이어가 없어 **서울 전체 수집, 페이지 완주, 공간 분할 중복 제거 및 25개 구 커버리지 검증은 수행하지 않았다**. 향후 적합한 VWorld 레이어가 확인되면 페이지별 `record.total`과 반환 고유 식별자 수를 대조하고, BOX 분할 경계의 중복 도형을 식별자 또는 근거 있는 도형 해시로 제거한다. 전체 범위를 25개 구 경계의 합집합과 비교한 다음 EPSG:5179에서 자치구별로 자르고, 산림·수역 합집합을 한 번만 차감한다. 총량·커버리지·기하 유효성 검증 전에는 Density를 확정하지 않는다.

## 선택 및 이용조건

**VWorld 후보는 채택하지 않는다.** 목록 갱신일은 실제 지표면 기준시점이 아니다. 두 후보의 실제 피복 기준시점과 레이어별 원도형 재배포 조건도 확인되지 않았다. 현재는 사용자가 제공한 [환경공간정보서비스 세분류 토지피복지도](https://egis.me.go.kr/intro/land.do) SHP를 우선 사용한다. 사용자 지시에 따라 [부분 커버리지 잠정 결과](results.md)를 계산했으며, 관측된 산림 311·321·331과 수역 711·712·721만 제외했다. 보호구역·하천구역으로 범위를 넓히지 않았다.
