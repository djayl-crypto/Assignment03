# EGIS 부분 커버리지 기준 잠정 결과

계산일: 2026-11-01. 사용자 지시에 따라 제공된 EGIS SHP 도엽에서 관측된 산림·수역만 자치구 경계에서 차감했다. 산림·수역 제작연도는 계산 조건에 넣지 않았다. 전체 25개 구 결과는 [JSON](../data/processed/analysis_preview.json)과 [CSV](../data/processed/analysis_preview.csv)에 있다. `status=provisional_partial_coverage`이며 외부 공개용 최종 결과가 아니다.

- 사업 358구역, 30년 이상 주택 960,148호, 전체 주택 3,215,847호.
- 자치구 전체 면적 합계 605.3012km². 관측 산림 133.5957km², 관측 수역 31.9138km², 제외 합집합 165.5095km², 잔여 면적 439.7917km².
- 서울 전체 Density: 전체 면적 기준 0.5914구역/km², 관측 산림·수역 제외 기준 0.8140구역/km². 두 값 모두 358구역을 각 서울 면적 합계로 나눈 값이다.

종로구와 노원구는 해당 구와 겹치는 원본 도엽만 별도로 다시 읽고, 원본 도형을 EPSG:5179로 변환해 산림·수역 합집합 면적을 독립 대조했다. 두 구의 산림·수역·제외 합집합 면적은 분석 CSV와 부동소수점 오차 범위에서 일치했다.
