# 웹 보고서 브라우저 검증 기록

검증일: 2026-11-01. 미리보기 주소: http://127.0.0.1:5174/.

## 흰 화면 원인과 수정

처음 안내한 5173번 Vite 개발 서버는 이 작업 경로의 `#` 문자 때문에 `/@vite/client`가 404였고, `src/main.tsx`를 변환하지 않은 TypeScript로 보냈습니다. 브라우저 콘솔의 `Unexpected identifier 'Metric'` 오류로 React가 실행되지 않았습니다. `npm.cmd run build`로 만든 `dist`를 Python 정적 서버의 5174번 포트로 제공해 해결했습니다. 빌드 JS와 집계 JSON·경계 GeoJSON·제외 영역 GeoJSON의 HTTP 200을 확인했습니다.

## 실제 브라우저 확인

VS Code 통합 브라우저에서 5174번 주소의 첫 화면과 서울 자치구 지도를 직접 확인했습니다. 보정 Density 지도와 LQ 지도를 전환하고, 관측 산림·수역 표시 레이어를 켰습니다. 지도에서 도봉구를 선택한 상세 카드가 나타났습니다. 산점도 기준선과 지표 범례, Density와 LQ 순위 전환, 순위에서 강북구 선택 시 산점도와 지도 상세값 연동을 확인했습니다. 표의 사업 수 열을 눌러 영등포구 30건이 맨 위로 정렬되는 것을 확인했습니다. CSV 버튼은 브라우저 저장 대화상자를 열었고, 실제 저장 파일에 25개 자치구가 있음을 확인했습니다. 브라우저 콘솔에는 오류 메시지가 0건이었습니다.

화면 폭 약 389px에서도 첫 화면, 지도, 지표 선택, 결과표와 CSV 버튼을 확인했습니다. 넓은 결과표는 모바일에서 가로 스크롤로 값을 확인합니다. 이 검증은 VS Code 통합 브라우저의 좁힌 뷰포트에서 수행했으며 별도 스마트폰 기기에서는 확인하지 않았습니다.

표시용 산림·수역 도형은 경계 안에서 15m로 단순화했습니다. 원자료에서 계산한 산림 133.5957305km², 수역 31.9137828km²와 표시 도형의 면적은 단순화 오차 범위에서 일치합니다. 표시 도형의 면적을 지표 계산에 사용하지 않았습니다.
