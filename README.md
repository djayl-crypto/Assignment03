# 서울 노후주택과 정비사업 밀도

서울 25개 자치구에서 **노후주택의 상대적 집중도는 높지만, 산림·수역을 제외한 면적당 진행 중 주거 정비사업 수는 낮은 곳**을 찾는 도시데이터분석 보고서다.

## 주요 결과

관심 지역은 **종로·강북·도봉·노원·강서·관악구** 6곳이다. 노후주택 LQ가 1보다 크고, 산림·수역 제외 면적 기준 사업 밀도가 서울 전체 기준인 **0.814구역/km²**보다 낮다. 노원구의 30년 이상 주택은 **112,588호**로 관심 지역 중 가장 많다.

분석 대상은 진행 중 주거 정비사업 **358구역**, 서울의 30년 이상 주택 **960,148호**다. 산림·수역을 제외하면 Density의 서울 기준값은 전체 면적 기준 **0.591**에서 **0.814구역/km²**로 바뀐다. 이번 자료에서는 관심 지역 6곳의 구성은 변하지 않았다.

## 계산과 자료

- **Density** = 진행 중 주거 정비사업 구역 수 ÷ 자치구의 산림·수역 제외 면적(km²)
- **LQ** = (자치구 30년 이상 주택 수 ÷ 자치구 전체 주택 수) ÷ (서울 30년 이상 주택 수 ÷ 서울 전체 주택 수)
- **기준시점**: 정비사업 2026년 6월, 주택 2025년 11월, 자치구 경계 2025년 2분기. 산림·수역은 사용자 제공 EGIS 세분류 토지피복지도에서 관측된 도형을 사용했다.

EGIS 도엽의 서울 전체 외접 범위 커버리지는 최대 **96.07%**다. 관측되지 않은 부분을 임의로 채우지 않았으므로 산림·수역 제외 Density와 관심 지역 판정은 **잠정치**다. 산림·수역 제외 면적은 개발 가능 면적을 뜻하지 않는다.

## 보고서와 재현

웹 보고서는 저장된 [25개 구 집계 JSON](public/data/report.json)과 경계·표시용 도형으로 빌드되며, 브라우저에서 원자료 API나 비밀키를 사용하지 않는다. 지도에서 Density와 LQ를 비교하고, 산점도·순위·보정 전후 그래프·정렬표를 살펴보거나 CSV를 내려받을 수 있다.

```powershell
npm ci
npm run build
python -m http.server 5174 --bind 127.0.0.1 --directory dist
```

로컬 주소: `http://127.0.0.1:5174/`

자세한 내용은 [분석 방법](docs/method.md), [자료 출처](docs/sources.md), [결과](docs/results.md), [요구사항 체크리스트](docs/checklist.md)에 정리했다. 원자료와 `.env`는 저장소에 포함하지 않는다.
